受診の対象

Q どなたでも申し込めますか。

当サイトは満40歳～74歳の方を対象とした健康診断の予約専用サイトです。本人確認の画面で、お名前・生年月日・健康保険証の情報を対象者名簿と照合して確認します。

Q 本人確認で「対象者ではありません」と表示されます。

ご入力の内容が名簿と一致しないか、まだ名簿に登録されていない可能性があります。画面に表示されるお問い合わせ先（電話：03-1234-5678）までご連絡ください。お調べします。

お申し込み方法

Q ご予約はどのように進みますか。

どちらから入るかで、順番が少し変わります。

「予約する」からお入りいただくと、会場・日時の選択 → 本人確認 → 情報の入力 → 内容の確認 → 予約完了の順です。
「対象かどうかを先に確認する」からお入りいただくと、本人確認 → 会場・日時の選択の順になり、はじめの2つが入れ替わります。

いずれも5つの手順で、画面の上部に今どこまで進んだかが表示されます。ご案内に沿って順にご入力ください。

Q 本人確認には何を用意すればよいですか。

健康保険証をお手元にご用意ください。お名前（漢字）・フリガナ・性別・生年月日と、健康保険証に記載された保険者番号・記号・番号をそのままご入力ください。フリガナはひらがなや半角で入力されても、全角カタカナに自動で変換します。

Q 個人情報を入力せずに、会場ごとの空き状況だけ先に見られますか。

はい。最初の画面の「予約する」からお入りいただくと、個人情報のご入力なしに会場ごとの空き状況をご覧いただけます。ご希望のお時間をお選びいただいた時点で、本人確認へご案内します。

一方、「対象かどうかを先に確認する」は本人確認から始まります。受診の対象かどうかを先に知りたい方はこちらをお選びください。

Q インターネットの操作が苦手です。ほかの方法で申し込めますか。

はい、郵送でもお申し込みいただけます。郵送の場合も、インターネットからのお申し込みと同じように受け付けます。申込書の様式や送付先についてはお問い合わせ先（電話：03-1234-5678）までご連絡ください。

ご予約の確定後

Q 予約した内容をもう一度確認したいのですが。

最初の画面の「予約を確認する」で予約番号をご入力いただくと、いつでもご予約の内容をご覧いただけます。予約番号もお忘れの場合はお問い合わせ先（電話：03-1234-5678）までお名前と生年月日をお知らせください。担当者がお調べします。

Q 予約番号は、あとから見直せますか。

メールアドレスをご入力いただいていれば、確認メールからいつでもご覧いただけます。メールの件名にも予約番号を記載していますので、メールボックスで「予約番号」と検索すればすぐに見つかります。受診の前日にお送りするリマインドメールにも同じ番号を記載しています。

メールアドレスをご入力いただいていない場合は、予約完了画面が番号をご覧いただける唯一の場所です。その画面で必ずお控えいただくか、印刷してください。英字の大文字と小文字を区別しますので、正確にお書き写しください。

番号がわからなくなった場合も、お問い合わせ先までご連絡いただければ担当者がお調べします。

Q 電話番号は必ず入力しなければいけませんか。

携帯電話と固定電話のいずれか一方は、必ずご入力ください。両方をご入力いただく必要はありません。

ご予約の変更・キャンセルのほか、会場の都合で日程が変わる場合にご連絡する手段が必要なためです。メールアドレスと違い、電話番号は省略できません。

Q メールアドレスは必ず入力しなければいけませんか。

いいえ、メールアドレスのご入力は任意です。ただし、ご入力がない場合は予約確認メールと受診前日のリマインドメールをお送りできません。その場合は、予約番号を必ずお控えください。

Q 予約を変更・キャンセルしたいのですが。

インターネットでの変更・キャンセルは承っておりません。受診日の3日前までに、ご予約の会場へお電話ください。担当者が対応いたします。会場の電話番号は予約完了画面と確認メールに記載しています。

Q 受診当日は何を持って行けばよいですか。

健康保険証と、予約番号がわかるもの（印刷したものやお控え）をお持ちください。

Q 1年に何回も申し込めますか。

いいえ、健康診断のお申し込みは1年に1回です。すでにご予約がある場合は、本人確認の画面でお知らせします。

オプション検査

Q オプション検査の費用は、いつどのように支払いますか。

オンラインでのお支払いはありません。オプション検査をお申し込みの場合は、受診当日に会場でお支払いください。

Q 希望するオプション検査が申し込み画面に出てきません。

オプション検査は、性別・年齢の条件に合うものだけが表示されます。条件に合わない場合は一覧に表示されませんので、対象の年齢・性別ではない可能性があります。ご不明な場合はお問い合わせ先（電話：03-1234-5678）までご連絡ください。

エラーが出たとき

Q 入力の途中で時間が経ち、はじめからやり直すよう表示されます。

本人確認は安全のため30分で期限が切れます。お手数ですが、本人確認からもう一度お進みください。

Q 選ぼうとした時間が、たった今埋まったと表示されます。

ほかの方が一足先にその時間をご予約された場合です。別のお時間か、別の日をお選びください。
